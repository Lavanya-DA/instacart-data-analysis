# Instacart Data Analysis — Grocery Retail Analytics

An end-to-end grocery retail analytics project using **Python, Pandas, Excel, and Power BI** to analyze customer purchasing behaviour, product performance, reorder patterns, and shopping trends.

## 📌 Project Overview

This project analyzes Instacart grocery order data to understand how customers shop, which products perform strongly, and what purchasing patterns can be identified from historical order behaviour.

The project follows a practical data analytics workflow:

**Data Understanding → Data Cleaning → Exploratory Analysis → Business Analysis → Visualization → Insights**

The analysis was performed using Python and Excel, with key findings presented through an interactive Power BI dashboard.

## 🎯 Business Objectives

- Understand overall customer ordering behaviour
- Identify frequently purchased products
- Analyse product and department performance
- Examine reorder behaviour
- Identify purchasing patterns across customers
- Analyse order timing and shopping frequency
- Generate business-focused insights from grocery transaction data
- Build an interactive dashboard for decision-making

## 🔄 Project Workflow

### 1. Data Understanding

Reviewed the available Instacart datasets to understand:

- Customer orders
- Products
- Departments
- Order sequence
- Reorder behaviour
- Order timing
- Product purchasing patterns

### 2. Data Cleaning & Preparation

Performed data preparation activities including:

- Dataset inspection
- Data type validation
- Missing-value checks
- Duplicate checks
- Data transformation
- Feature preparation
- Joining relevant datasets for analysis

### 3. Exploratory Data Analysis

Analysed:

- Order trends
- Product popularity
- Department performance
- Reorder behaviour
- Customer purchasing patterns
- Order timing
- Product-level activity

### 4. Business Analysis

The analysis focused on identifying patterns that could support:

- Product planning
- Customer retention
- Reorder strategy
- Inventory decisions
- Promotional planning
- Customer engagement

### 5. Power BI Dashboard

An interactive Power BI dashboard was created to present the analysis through visual KPIs, charts, and business insights.

The dashboard allows users to explore the data and identify important purchasing and product-level patterns.
